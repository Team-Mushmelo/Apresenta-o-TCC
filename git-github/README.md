# O que é Git e GitHub

![Logo do GitHub](/img/github.png)

</div>

## Git

[Git](https://git-scm.com) é um sistema de controle de versão distribuído, o que significa que é uma ferramenta usada para rastrear mudanças em arquivos ao longo do tempo. Pense nele como um mecanismo que registra cada alteração feita em um documento, permitindo que você veja o histórico completo de modificações, reverta para versões anteriores e trabalhe simultaneamente em diferentes versões de um projeto.

### GitHub

[GitHub](https://github.com/) é uma plataforma de hospedagem de código-fonte baseada na web que utiliza o Git para controle de versão. Ela permite que desenvolvedores armazenem, colaborem, gerenciem e compartilhem seus projetos de software de forma eficiente.
